# MCA config files

These files must be in the format \d{2}_name.(toml|ini|json)
files must be formatted appropriately for their type
the higher the number to higher precedence

00 - application defautls

0X - production defaults

10 - unit defaults

20 - vendor defaults

30 - project defaults

40 - deployment defaults

--- Factory reset 

50 - technician settings

-- config reset

80 - current settings


90 - overrides
